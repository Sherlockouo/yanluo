出稿 · redesign · Variant B · 2026-07-16

一面输入，一条流。

出稿重设计：把顶部的等权胖 TAB 条换成单一自适应输入面——它随选择的活儿变形（拖文件 / 贴链接 / 开实时 / 开翻译），模式切换是输入面内部的安静控件，不再是切页面的标签栏。输入面下方是一条连续的统一流：转写、实时、翻译、历史都是同一条时间线，用安静的类型标签区分。全页只有一个亮橙主行动。

令牌：暖净纸 #F4F2EE / 卡面白 #FFFFFF / 墨 #1C1A17 / 亮橙 #D9722E（唯一主 CTA + 录音灯）/ 深橙小字 #A0561F。
组织概念：①「自适应输入面」= 页面唯一焦点，随模式变形；②「统一流」= 冷静、可扫读的记录时间线；③ 模式切换 = 输入面内的安静点选控件（不是切页 TAB）；④ 翻译/历史等次级配置走标题区展开或流内过滤 chip，绝不做页脚配置坟场。
本稿含 7 帧：文件上传 · 网络链接 · 处理中(识别/下载%) · 转写结果+详情 · 实时(引擎+HUD) · 翻译(SemanticPair) · 历史(统一流+清理)。
